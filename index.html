Course Lessons

Lesson 1: Basic Page Structure

Published on 2 November 2026

Every HTML page starts with a document type and an html element. The head holds page settings and the body holds the visible content. 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My First Page</title>
</head>
<body>
    <h1>Hello, World!</h1>
</body>
</html>

Lesson 2: Headings, Paragraphs and Links

Published on 3 November 2026

Use h1 to h3 for headings, p for paragraphs and a for links. A link needs an href attribute. 

<h2>My Heading</h2>
<p>This is a paragraph.</p>
<a href="https://example.com" target="_blank">Visit Example</a>
