Course Lessons

Lesson 1: Basic Page Structure

Published on 2 November 2026

Every HTML page starts with a document type and an html element. The head holds page settings and the body holds the visible content. 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My First Page</title>
</head>
<body>
    <h1>Hello, World!</h1>
</body>
</html>

Lesson 2: Headings, Paragraphs and Links

Published on 3 November 2026

Use h1 to h3 for headings, p for paragraphs and a for links. A link needs an href attribute. 

<h2>My Heading</h2>
<p>This is a paragraph.</p>
<a href="https://example.com" target="_blank">Visit Example</a>

Lesson 3: Working in Visual Studio Code

Published on 4 November 2026

After writing your code, save the file by pressing Ctrl + S. To format your code, press Shift + Alt + F.

After you save your work with Git, the terminal shows a message like this: 

[main c060c44] Add basic HTML structure and page title
 1 file changed, 12 insertions(+)

Extra Notes

  • Practice every new tag in a small file before using it in a project.
  • Indent your code with 4 spaces so it is easy to read.
  • Use meaningful names for every id and class.
