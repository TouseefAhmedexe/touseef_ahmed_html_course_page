# HTML Fundamentals Course Page

A course page for an HTML training program, built with HTML only (no CSS, no JavaScript).
This is Task 3 of my Bloomrix internship.

## Features
- Header, navigation, main content and footer
- Sections with article lessons and aside notes
- Course image with figure, figcaption and picture
- Audio, video and a text track
- Embedded page with iframe, plus object and embed
- Quotations, code examples and keyboard shortcuts
- Expandable FAQ and a dialog example

## Files
- index.html - the course page
- images/ - course banner images
- media/ - audio, video and caption files
- pages/html-cheat-sheet.html - page embedded with iframe

## How to run
Open index.html with Live Server in Visual Studio Code, or in any web browser.
